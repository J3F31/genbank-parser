# Gene bank file parser

## Description

Read gene bank `.gb` files and extract data.<br>
Additional class support for analyzing sequences.

## Getting Started

### Dependencies

### Executing program

Run genbank.py script followed by filenames.
```
python3 genbank.py AB001981.gb AF165912.gb L00727.gb NM000492.gb NM000518.gb NM_001204686.gb NM_001316489.gb U49845.gb
```
